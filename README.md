# AI Pathfinder

AI Pathfinder is a prototype that helps students explore possible career and higher-study pathways based on their interests, goals, preferred country, and budget.

## What it does

The application asks the user a few questions and provides:

- A suggested direction based on the selected goal and field
- A learning roadmap for the selected field
- University options for selected countries
- Basic funding and scholarship direction
- Suggested next steps

## Current Features

The current prototype includes pathways for:

- Artificial Intelligence & Machine Learning
- Data Science
- Software Development
- Cybersecurity
- Business & Management
- Design & Creativity

It currently includes university information for Germany, with plans to add more countries and opportunities in future versions.

 ##Technologies Used

- Python
- Streamlit

## How it works

The application uses Python dictionaries to store roadmap and university information. Streamlit is used to create the web interface.

Based on the user's selections, the program uses basic rule-based logic to display a suitable roadmap and relevant university information.

##Future Improvements
